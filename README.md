# Qubes Artwork

The official artwork and branding for [Qubes OS](https://www.qubes-os.org). It holds the Qubes logos, application and qube-type icons (in many sizes, including scalable SVG), desktop wallpapers, the Plymouth boot splash theme, the rEFInd (EFI) boot theme, Apple EFI boot-selector graphics, and the Anaconda installer theme.
